- An interactive logo design for "Hongkong Banjum 0410". Holding the space bar turns the mouse cursor into a banknote. Cutting a bundle of noodles with the banknote makes them fall into the bowl below, transforming into wriggling mussel jjamppong (spicy seafood noodle soup).
- Developed using Processing and the [toxiclibs](https://github.com/postspectacular/toxiclibs) library.

## Description

An interactive logo-design Processing sketch for the Chinese restaurant "Hongkong Banjum 0410." Pressing the spacebar turns the mouse pointer into a banknote; sweeping it across the screen to cut the noodles makes them drop into the bowl below, completing a jjamppong.
:::

:::ko
## 설명

중화요리점 "홍콩반점0410"의 인터랙티브 로고 디자인 Processing 스케치. 스페이스 키를 누르면 마우스 포인터가 지폐가 되고, 그대로 화면을 가로질러 면을 자르면 아래 그릇으로 떨어져 짬뽕이 완성된다.
:::

:::ja
## 説明

中華料理店「香港飯店0410」のインタラクティブ・ロゴ・デザインProcessing sketch。スペース・キーを押すとマウス・ポインターは紙幣になり、そのまま画面を横切って麺を切ると下の皿に落ち、チャンポンが完成される。
